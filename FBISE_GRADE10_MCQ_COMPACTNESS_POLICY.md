# Grade 10 MCQ Compactness and Cognitive-Transfer Policy

## Purpose

This policy addresses a practical printed-paper requirement: a Grade 10 MCQ must be easy to scan, physically mark, and understand under examination time. It is **not** a blind character or word limit. The intended form comes from the supplied paper evidence and the active textbook exercise, while the active textbook remains the only authority for factual answers.

> **Boundary:** Model papers and annual papers show how an MCQ is presented. They do not supply facts, answers, or future-paper predictions. Textbook exercises show practice form; they must not be copied or lightly reworded into generated questions.

## Generation Policy

| Area | Required form | Not permitted |
|---|---|---|
| Stem | One clear tested relationship: definition, classification, purpose, representation, short trace, calculation, or familiar consequence. | Multi-paragraph scenarios, background stories, or a question that combines unrelated learning objectives. |
| Scenario | Use only when application is genuinely needed. Include the smallest set of facts required to choose an answer. | Decorative names, settings, explanations, or outside knowledge that merely make the question longer. |
| Numerical / code / logic item | Show the essential number, expression, code fragment, truth-table relation, or unit. | Removing essential working data merely to make the item shorter. |
| Options | Present answer-shaped choices: a term, value, operator, compact code form, or concise consequence. | Explanatory paragraphs, trick wording, or distractors that demand more reading than the tested idea. |
| Textbook exercise transfer | Shift the tested relationship while remaining within the same verified textbook concept: changed value, representation, condition, or familiar application. | Copying, paraphrasing, or memorisation-only replay of an end-of-chapter MCQ. |
| Past-paper pattern | Use concise command style, one-mark form, and physical-paper readability where the reviewed profile supports it. | Importing a past-paper fact, answer, code topic, or older-syllabus content that is not in the active textbook scope. |

## Content-Safety Rules

The active Computer Science textbook is from Curriculum 2022–23. Therefore, a compact paper form observed in older material does **not** authorise content that is outside that textbook. In particular, an observed code-trace, logic, or web-tag form may guide compact presentation only if the selected textbook scope contains the required factual concept.

The same rule applies to Physics and Chemistry: their papers can guide concise one-mark presentation only after the selected programme’s active textbook confirms the concept. Subject papers, shifts, and Practical-Based Assessment material remain isolated.

## Subject-Isolated Extension

Physics is now included in the compactness calibration. Its 2026 evening paper and active user-supplied textbook exercise support direct one-mark forms: short definitions, a single physical relationship, a minimal numerical substitution, or a familiar condition with answer-shaped options. The universal prompt therefore applies these compact forms while the selected Physics textbook controls every fact and calculation.

Chemistry is deliberately **not** assigned exercise-transfer guidance yet. The only retained Grade 10 Chemistry textbook source is archived (`2020 NBF textbook · OCR-reviewed transcript`), so it is not eligible to authorise Chemistry facts or exercises. The reviewed 2026 Chemistry evening-paper profile remains isolated format evidence only. This prevents a false appearance of cross-subject consistency based on an unapproved book.

## Implemented Control

The MCQ generation prompt now requires compact printed-paper forms, compact answer-shaped options, minimal necessary data in numerical/code items, and textbook-supported transfer beyond memorised exercise wording. It deliberately does **not** impose a global word or character cap, because correct binary strings, equations, code snippets, and a necessary contrast can be longer than a simple definition while still being physically readable.
