## Confirmed Strengths

The active curriculum catalog requires both a ready programme and an active curriculum set with active chapters. Textbook source extraction and OCR-page review are gated before set activation. Paper-pattern profiles are separate from textbooks and must be reviewed before activation. Generation source resolution obtains factual scope text only through the active curriculum catalog, while paper profiles flow into style guidance separately. These are retained safeguards, not candidates for removal.

The production dependency audit completed with **zero reported production-package advisories**. The Gemini fallback routes only after a managed-provider quota-exhaustion classification, retains provider-specific retry/circuit telemetry, and is operationally distinct from the managed provider. The current evidence does **not** justify replacing either provider or weakening source/structured-output validation. The confirmed metadata and citation-evidence defects above should be repaired independently of model selection.

Live visual check on the published route confirmed F-011: the signed-out Grade 9/10 landing presents **Open draft library**, and selecting it reaches the protected library’s loading state instead of an explicit staff sign-in boundary. The hosting-layer banner visible above the application reports a platform billing/availability state; it is external to the application code and is not treated as a code defect in this register.

After the repair, the latest development build visually presents **“Staff sign in to open drafts”** beside the Grade 9 and Grade 10 cards; the action is now backed by a no-query signed-out redirect regression. The production build completed successfully. It reported one non-blocking frontend-bundle optimization observation: the main minified JavaScript chunk is approximately 685 kB before gzip (approximately 199 kB gzip). This is recorded as a performance follow-up, not an immediate functional or security failure; code splitting should be considered only after real loading measurements identify a user-visible delay.

The final browser check on the Portal Admin route was correctly rejected for the browser’s non-admin session. This confirms the visible role boundary; the grade-local Portal Admin layout is therefore verified by its dedicated component regression suite rather than by pretending the browser session had administrator authority.

## Approved Minimal Remediation Map

| Work item | Decision | Reason it is the smallest safe change |
|---|---|---|
| Paper-pattern uploads | Move strict base64 decoding and MIME-signature validation into a shared protected helper used by paper-pattern intake before extraction/storage. | Reuses the existing textbook controls rather than creating parallel validation rules. |
| Chunk completion | Store completion state and the created source receipt inside the durable upload-state document. A repeated complete request returns that source instead of re-ingesting bytes. | Repairs only the ambiguous-final-response failure path; no new storage platform or background service is introduced. |
| Programme identity | Normalize board/grade/subject at the server boundary; validate that a requested replacement ancestor has the same normalized programme identity. | Preserves the current Programme Catalogue schema and unique index while eliminating API-level duplicate and lineage fragmentation. |
| Citation evidence | Validate that a normalized text anchor is present in the resolved textbook scope before accepting a curriculum-scope draft. | Strengthens the existing source-citation contract without making unsupported semantic claims about exact answer derivation. |
| Provider provenance | Save the provider and non-secret telemetry already present on the generation job, instead of a stale constant. | Corrects audit data without changing provider routing or model behavior. |
| Signed-out library | Keep public ready-programme metadata because the unauthenticated landing deliberately shows Grade 9/10 readiness, but gate the draft library UI and its query behind staff authentication. | Removes the real error path without breaking the current signed-out grade-selection view. |
| Grade/subject intake | Retain Programme Catalogue → Curriculum Set → Source. Replace the generic programme form with grade cards, a grade-local subject list, and an admin-only Add subject action. The existing focused intake remains the subject/textbook path. | Reorganizes a sound backend model rather than replacing records or lifecycle controls. |
| Paper source timeline | Add nullable `timelineOrder` and `timelineLabel` to paper-pattern records. Require an ordinal for past papers, render them oldest-first under the selected subject, and retain model papers separately. | Captures the requested 1, 2, 3 chronology without inventing dates, shifts, or predictions. |

**F-003 decision:** retain public read-only programme/catalogue metadata. It contains no textbook text and supports the deliberate signed-out Grade 9/10 selection view. All source content, drafts, reviews, uploads, staff data, provider settings, and activation mutations remain server-authorized.
