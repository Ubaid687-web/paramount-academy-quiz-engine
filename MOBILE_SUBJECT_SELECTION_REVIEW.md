# Mobile Subject-Selection Review

## Live review — 13 August 2026

The refined Quiz Centre landing page now uses the Paramount Academy palette and a calmer visual hierarchy: compact branded header, clean white hero surface, more restrained type scale, and balanced Grade 10/Grade 9 cards. The page no longer has the oversized, generic card treatment visible in the supplied screenshot.

The Grade 10 subject screen presents a real **Change class** button with an accessible return label. Subject cards now have distinct subject icons and restrained accent colours for Physics, Chemistry, and Computer Science while retaining the same single-action teacher workflow. The cards are compact enough to stack cleanly on mobile and expand into a three-column layout on wider screens.

The visible return action was verified through both live interaction and automated UI coverage. It now returns to class selection instead of resetting the same Grade 10 subject screen.

The final live verification also confirmed that the return control is exposed as an accessible button named **Return to class selection**, while its teacher-facing label remains **Change class**. This preserves a short, understandable mobile label without sacrificing keyboard and assistive-technology clarity.
