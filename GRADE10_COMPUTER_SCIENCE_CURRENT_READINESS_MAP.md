# Grade 10 Computer Science: Current Textbook-to-Paper Readiness Map

## Status and Purpose

This is an **interim, evidence-bound Grade 10 map**. It uses the active NCP 2022–23 Computer Science textbook together with the supplied model paper and 2024/2025 annual papers. It does not predict the 2027 paper, estimate exact repeat probabilities, or treat older questions as a syllabus. The full 2026 Grade 10 Computer Science annual paper is still required before a final recurrence review can be completed.

> **Working rule:** A student should memorise the current textbook first. A paper form is useful only when its concept is directly supported by the active textbook. The extra task is to recognise that same concept after FBISE changes the wording, context, format, or cognitive demand.

## What the Current Evidence Shows

The supplied papers do not support a blanket conclusion that every older form will remain current. Their strongest evidence is for a set of **textbook-supported transformations**: direct definitions becoming an MCQ, comparison-table material becoming a short “differentiate” response, a worked method becoming a small calculation or trace, and a factual description becoming a familiar scenario. The most important readiness gap is therefore not “more random questions”; it is moving students from **remembering the textbook point** to **recognising its tested form**.

| Status | Meaning for preparation |
|---|---|
| **Confirmed** | The exact concept is in the active textbook and a supplied Computer Science paper shows a comparable assessment form. It may be used for structured memorisation and textbook-faithful practice. |
| **Unconfirmed** | The concept is in the book, but no comparable supplied paper form was found. Teach it as current textbook content, but do not call it a recurring paper priority. |
| **Outside / unsupported** | A supplied paper form requires detail not directly established in the active textbook. Do not use it to set a 2027 memorisation target or generate a task. |

## Applied-Knowledge Preparation: The Missing Step

Applied knowledge should not mean outside facts or difficult English. For every assigned topic, teachers can use this controlled three-part study sequence.

| Step | Student task | Example of the required thinking—not a predicted question |
|---|---|---|
| **1. Recall** | Memorise the textbook definition, rule, comparison row, diagram label, method, or code feature. | “What does the book say a process scheduler does?” |
| **2. Explain** | State the purpose, difference, cause, effect, or sequence in plain textbook words. | “Why does the scheduler matter when several programs run?” |
| **3. Recognise in context** | Identify the same verified concept in a short familiar scenario, table, conversion, code fragment, or diagram. | “A computer slows while many applications are open: which two verified OS functions are relevant?” |

This sequence is useful because the active textbook already provides the factual answer, while the supplied papers show that FBISE often changes **the form of recall**, not necessarily the underlying concept.

## Student-Facing Topic Assignment Structure

Teachers do not need to give students an uncontrolled question bank. For each selected textbook topic, assign a compact revision sheet containing the following items:

| Sheet part | Required content |
|---|---|
| **Learn exactly** | Textbook definition, rule, diagram labels, formula/process, table rows, or syntax feature. |
| **Explain clearly** | Two to four short points using the same accessible terms as the textbook. |
| **Compare where relevant** | A textbook-supported two-column comparison, such as system/application software or supervised/unsupervised learning. |
| **Recognise in a situation** | One non-predicted everyday context that requires the student to identify the already-memorised concept. |
| **Check boundary** | A source reference to the exact approved unit/exercise; if one is missing, the item is not assigned as a paper-preparation priority. |
